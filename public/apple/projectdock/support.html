ProjectDock 用户支持

支持邮箱：n_sir@sina.com

提交问题前

  1. 确认使用最新版本。
  2. 运行 projectctl doctor 并只分享不含私有路径或密钥的结果。
  3. 说明 macOS 版本、ProjectDock 版本、复现步骤和预期结果。

安全提示

不要通过邮件或公开 Issue 发送 API 密钥、Apple/GitHub 凭证、私有仓库内容、完整项目日志或未脱敏的本机路径。安全问题请在邮件主题中注明“ProjectDock Security”。

开源支持

普通缺陷和功能建议可提交到 GitHub Issues。

English

For support, email n_sir@sina.com or open a GitHub issue. Never include API keys, private repository content, credentials, or unredacted local paths.
