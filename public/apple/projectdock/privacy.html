ProjectDock 隐私政策

生效日期：2026 年 8 月 6 日

ProjectDock 由野路子工作室提供。开发者不运营 ProjectDock 云端账号、广告或分析服务，也不接收或存储你的项目注册表、项目路径、运行日志或 API 密钥。

本机数据

项目登记、端口分配、审计记录、AI 设置和运行日志保存在你的 Mac。AI 密钥使用 macOS 钥匙串保存。删除 APP 不一定自动删除这些本机支持文件，你可以在删除前通过 APP 移除项目登记，或手动删除 ProjectDock 的本机支持目录。

AI 模型服务

只有在你主动配置并使用 AI 分析时，ProjectDock 才会把有限的 README 和常见依赖清单直接发送到你选择的模型服务。开发者不会中转该请求。第三方服务会依据其自身条款处理数据；请勿向不受信任的服务发送敏感项目内容。

GitHub

只有在你主动安装 GitHub 项目时，ProjectDock 才会直接连接 GitHub，克隆你提供的公开仓库地址。开发者不会接收该请求。

桌面组件

Widget 只通过 App Group 读取脱敏的本机摘要，不读取项目路径、命令、PID、日志或密钥。

保留、删除和联系

开发者没有可删除的服务器端 ProjectDock 账户数据，因为这些数据不会被开发者收集。关于本机数据删除或隐私问题，请联系 n_sir@sina.com。

English summary

ProjectDock is local-first. The developer does not operate cloud accounts, advertising, or analytics for ProjectDock and does not receive your registry, paths, logs, or API keys. Optional AI requests go directly to the provider you configure; optional repository installation connects directly to GitHub.
