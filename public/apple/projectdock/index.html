macOS · Open Source

ProjectDock

一个在你的 Mac 上运行的本地项目控制台，用于登记项目、管理授权目录、安装 GitHub 项目、配置 AI 分析、审计操作和测试本地 API。

本地优先

项目注册表和运行记录默认保存在本机。ProjectDock 不运营云端账号或分析服务，也不会把完整项目目录上传给开发者。

开放与透明

源码按 Apache License 2.0 开放。AI 分析和 GitHub 安装都是用户主动选择的可选能力，外部请求直接发送到用户配置的服务。

商店版边界

Mac App Store 沙盒版只访问你明确授权的目录，并隐藏系统级端口扫描、任意命令启停和彻底删除等需要更高权限的能力；GitHub 完整版提供完整的本机开发控制能力。

GitHub 源码隐私政策用户支持

ProjectDock is a local-first macOS console for projects, ports, controlled processes, logs, and local API testing.
