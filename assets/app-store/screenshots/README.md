# App Store 产品宣传截屏

本目录包含 ProjectDock 的 macOS App Store 宣传截屏及可复现模板。

- `source/`：真实应用界面截屏与无文字品牌背景。
- `zh-Hans/`：提交 App Store Connect 的简体中文成品，尺寸均为 2880×1800 PNG、无透明通道。
- `marketing.html`、`marketing.css`、`marketing.js`：确定性排版模板；通过 `?slide=1` 至 `?slide=8` 选择画面。

界面、功能状态和对话框均来自真实运行的 App Store 沙盒构建。品牌背景由图像生成工具创建，不包含应用界面、文字、人物或第三方标识。
